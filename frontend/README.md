# CareVYA

Next.js frontend for **CareVYA** — a marketplace connecting families with verified caregivers and care agencies.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js App Router, TypeScript, Tailwind CSS, React Hook Form + Zod, TanStack Query, Zustand, Framer Motion.
